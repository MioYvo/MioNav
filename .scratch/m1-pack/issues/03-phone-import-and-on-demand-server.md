# 03: 手机侧：导入、按需开服务、HELLO 回 URL

**What to build:** 手机上导入一个 `.mbtiles` 就有可分享的包。手表连上来报告自己的版本后，只有确实过期才开服务，并把 URL 回给手表。

**Blocked by:** 01 (`core/pack` 与三条路由).

**Status:** ready-for-agent

- [ ] 通过系统文件选择器导入一个 `.mbtiles`，不需要存储权限
- [ ] 缺 manifest 时现场算出 sha256、字节数与瓦片数并补写一份
- [ ] 手表 identity 与本地一致：回空 url，**端口从不绑定**
- [ ] identity 不一致：启动服务，回 `http://<局域网地址>:<实际端口>`
- [ ] 手表下载校验通过并回新 identity 后，服务立即停止
- [ ] 10 分钟没有 HTTP 请求自动停；蓝牙断连超过 60 秒且传输未完成也停
- [ ] 手机没有任何局域网地址时回空 url，界面提示先开热点或连 Wi-Fi
- [ ] 界面显示当前包名、版本、大小与完整 URL，并有一个手动「共享底图」开关
